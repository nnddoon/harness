# T-020 bash 3.2 兼容与调度小修

## 1. 背景与目标
macOS 系统 bash 3.2 在 UTF-8 下把 `$VAR（` 的全角字节当成变量名，set -u 下直接退出（F-8）；顺带修调度器派发 proposed 任务（F-11）与 backlog-status 无参数报错。

## 2. 范围
**做：**
- 所有 `$VAR` 后紧跟非 ASCII 的地方改 `${VAR}`
- lint 测试：扫描 pkg/scripts 与构建后的 payload，禁止该模式；禁止 bash 4 特性（关联数组、${var,,}、mapfile 等）
- pick-batch 只取 ready；backlog-status 无参数打印用法

**不做（明确排除）：**
- 不改脚本行为

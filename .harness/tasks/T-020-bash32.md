# T-020 bash 3.2 兼容与调度小修

## 1. 背景与目标
macOS 系统 bash 3.2 在 UTF-8 下把 `$VAR（` 的全角字节当成变量名，set -u 下直接退出（F-8）；顺带修调度器派发 proposed 任务（F-11）与 backlog-status 无参数报错。

## 2. 范围
**做：**
- 所有 `$VAR` 后紧跟非 ASCII 的地方改 `${VAR}`
- lint 测试：扫描 pkg/scripts 与构建后的 payload，禁止该模式；禁止 bash 4 特性（关联数组、${var,,}、mapfile 等）
- pick-batch 只取 ready；backlog-status 无参数打印用法

**不做（明确排除）：**
- 不改脚本行为

## 接口约定（tester 写，builder 照此实现；测试：`bash pkg/tests/test_bash32.sh`）

**L. lint（S-003#5 / F-8）。** 扫描范围：`pkg/scripts/*.sh`，以及 `bash pkg/plugin/build.sh <临时目录>` 构建结果里所有 `*.sh` 和首行是 bash shebang 的文件（当前是 `payload/scripts/*.sh`、`payload/.harness/{verify,quick-check}.sh`、`hooks/notify.sh`）。lint 由测试里的 python3 按**字节**匹配（与 locale 无关），每处违规报「文件:行: 规则」。
- (a) 规则 `nonascii`：`\$[A-Za-z_][A-Za-z0-9_]*[\x80-\xff]` 一处都不许有，**注释行也算**。修法只有一种：`$VAR（` → `${VAR}（`（机械替换，不改逻辑）。`${VAR}`、`$1（` 这类位置参数、`$VAR` 后面跟 ASCII 都不算违规。当前命中 16 处：gate-sync.sh:41,46,48；gates.sh:39；harness-loop.sh:129,155,158,182,186,189,226,238,281,303,362；new-task.sh:81。payload 是构建时复制的，改源文件即可。
- (b) 规则 `bash4`（整行注释不查）：`declare -A`、`local -A`、`${v,,}` `${v^^}` `${v,}` `${v^}`、`mapfile`、`readarray`、`|&`、`&>>`、`coproc`、`;&`、`;;&`。当前 0 处，保持为 0。
- (c) 实跑：`${HARNESS_TEST_BASH32:-/bin/bash}` 的 `BASH_VERSINFO[0]` 是 3 时，对每个被扫描的脚本跑 `LC_ALL=en_US.UTF-8 bash -n`（退出 0），再在一次性仓库里用假 claude、gh、crontab（`HARNESS_CLAUDE`、`HARNESS_CRONTAB`、`pkg/tests/fake/gh`）做冒烟：`harness-loop.sh --dry-run [--integration] --max-tasks 1 --no-groom --no-replan`、`gates.sh --all`、`gate-sync.sh`、`new-task.sh T-001 --print-only`、`new-task.sh`（不带参数）。冒烟只要求输出里没有 `unbound variable`、`bad substitution`、`syntax error`，不检查退出码。不是 3.x 就打印 `SKIP bash 3.2 实跑：…`。调试开关：`HARNESS_TEST_BASH32_FORCE=1`（非 3.x 也跑）、`HARNESS_TEST_UTF8_LOCALE`（默认 `en_US.UTF-8`）、`HARNESS_TEST_SMOKE_SHOW=1`（打印冒烟输出）。
- lint 自带正反对照样例（自检），保证规则本身不漏报、不误报。

**S. 调度（S-003#9 / F-11）。**
- `harness_lib.py pick-batch N [--skip ids]` 只返回 **new-task.sh 会认领的任务**：backlog 行 `ready`，**且**主仓库任务卡 frontmatter 的 `status` 是 `ready` 或 `claimed`。`claimed` 是整合失败重开的情况：line 189 用 `--backlog-only` 把 backlog 改回 ready，卡上仍是 claimed。F-11 的成因：groom 把 backlog 行转成 ready，卡上仍是 `proposed`。没有任务卡的行照旧处理（本任务不改）。其他规则不变：deps、路径重叠、unscoped 任务单独派、优先级排序。`next-ready` 建议用同一个过滤（不测）。
- `harness_lib.py backlog-status`（不带参数）：退出码 2；stdout 为空；stderr 一行用法，必须包含 `用法` 和 `backlog-status T-xxx`，例如 `用法：harness_lib.py backlog-status T-xxx`；没有 Traceback。带参数时行为不变：已知 id 打印状态，未知 id 打印空行，都退出 0。

## 接口约定 v2（第 2 轮，基于 57f3d71；测试同一文件，名字带 `v2` 或在 lint 自检 / 逐文件 (b)(d) 里）

**L(b) 扩充（同属规则 `bash4`，整行注释不查；每条在自检里都有必中样例，另有一组 bash 3 写法的反例保证不误报）：**
`typeset -A`、`declare|typeset|local -n/-g/-l/-u`、`[[ -v` / `[ -v` / `test -v`、`${v@op}`（任意 @ 运算，含 `${a[@]@Q}`）、负下标 `${a[-1]}`（`${s: -1}` 截取不算）、`wait -n`、`$EPOCHSECONDS` / `$EPOCHREALTIME`、`$BASHPID`、`shopt` 提到 globstar/lastpipe/autocd/checkjobs/dirspell/globasciiranges/direxpand/inherit_errexit/localvar_inherit/assoc_expand_once（bash 3.2 连 `-u` 这些名字都报错）、`{fd}>` 一类具名 fd 重定向（`${fd}>` 不算）、`read -i` / `read -N`、带步长的 `{1..9..2}`。当前 pkg 和 payload 里 0 处。

**L(d) 新规则 `array`：** 文件里有 `set -…u…` 或 `set -o nounset` 时，`${X[@]}` / `${X[*]}` 的裸展开（不论有没有引号）都必须有保护。算作有保护的写法：`${X[@]+"${X[@]}"}`、`${X[@]:+…}`、`${X[@]:-…}`、`${#X[@]}`。原因：bash < 4.4 在 set -u 下展开空数组会报 unbound variable。白名单 `ARRAY_ALLOW="GIT MGIT CTL CTLLIB LAUNCH"` 写在测试里，名单上的名字可以不加保护，但测试会自检：在用到它的每个脚本里，它都要赋过非空字面量，而且从没赋成 `()`。当前违规 3 处，都在 harness-loop.sh：284、286 的 `"${RES[@]}"`，342 的 `"${LAUNCHED[@]}"`。修法是机械地改成 `${RES[@]+"${RES[@]}"}`，不要把它们加进白名单（有计数守卫也不算，lint 看不出来）。

**S(3) waves：** 判定「backlog 行 ready 但卡片不可认领」用的是 `claimable()`，这样的行和 proposed 同样处理：不进 todo，也不算 inflight，不出现在任何一批里。卡片转成 ready/claimed 之后，第 1 批就是 pick-batch 能派的。fixture 的期望输出是 `第 1 批: T-030 T-034`，T-031 的卡转 ready 后变成 `第 1 批: T-030 T-031 T-034`。

**S(4) 跳过提示：**
- pick-batch 对每个 backlog 行 ready、不在 `--skip` 里、但卡片不可认领的任务，在 stderr 打一行 `跳过 T-xxx：任务卡状态是 <s>`。冒号是全角，`<s>` 是卡上的 status 原样。这个提示与 N 无关，pick-batch 1 也照样打。stdout 不变。
- 卡片转 ready 后不再打。没有卡片的行不打（它按 claimable 规则可以派）。
- harness-loop.sh 写晨报时（`--integration` 或 `--until`），`.harness/reports/morning-*.md` 要把本轮被跳过的任务各列**一次**，每行里包含上面那行原文；可以派的任务不列。怎么收集（例如捕获 pick-batch 的 stderr、去重后写一个文件，再像 expired-cron 那样追加到晨报），由 builder 决定。

**L(c) 冒烟扩充（只在 bash 3.x 或 `HARNESS_TEST_BASH32_FORCE=1` 时跑）：**
- 测试内置的假 gh：`auth status` 退出 0，`repo view` 给 `acme/widget`，其余回 `[]`。gate-sync 不得输出「gh 未登录或不是 GitHub 仓库」，也不得有 Traceback。
- 假 crontab 用 `$CRONFILE`，读完 stdin 再替换。夹具里放一行过期的本仓库定时任务 `expires=2000-01-01` 和一行别的任务，再用 `HARNESS_NOW=bogus` 跑 gate-sync。期望：输出有 `定时任务已到期（expires=2000-01-01）` 和 `HARNESS_NOW 不是数字（bogus）`；本仓库那行被删，别的任务保留；`expired-cron.txt` 写入。本机 bash 5 下用 FORCE 跑时这组已经通过；它要防的是 bash 3.2 在 UTF-8 下回归。

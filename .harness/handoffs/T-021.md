# T-021 交接包：任务生命周期修正

## 变更摘要
- 任务不会锁住自己：own_task_paths 让规则 4、control-diff、strict 放行本任务自己的卡和交接文件。
- 答复过的门卡能解开 blocked 任务：统一入口 release_blocked(main, tid, root, since_ns)（CLI `--since-ns`），以主仓库 backlog 与卡为准；还有 open 门卡、被拒的 unlock 且之后没有批准、比最新答复更新的 ctl 快照时不放行。
- waiting_human 保留 in_progress + RESUME 接续，并同步主仓库 backlog 行。
- unlock 门卡缺 paths 不快照，发布 hook 与 gate-sync 给出同一提示。
- 答案库每条答复与 meta 快照多存 at_ns，先后比较用纳秒（旧记录按 at 换算）。
- harness-loop.sh 启动时记纳秒；finish() 只在卡自己记 blocked 时、且只认本次会话期间的答复做复核；ctl / stray / task-branch / base-check 拦截一律计入 BLOCKED 走 replan。

## 遗留问题
- 低：会话内开出、答复规则为 auto 的 ambiguity 门卡，会话结束后会放行、不进 replan。可在 S-004 收紧。
- 标准模式下答案库与审计日志只靠守卫保护（S-002 已知残留）。

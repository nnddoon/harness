# T-014 交接包：分支保护向导

## 变更摘要
- `harness init`（含 setup）安装后只读检查分支保护：`gh repo view --json url,...`、GET protection、GET actions/permissions/workflow，全部带 `--hostname`，超时 10 秒。
- 能开但未开 → 开 external 门卡 `G-SETUP-bp`，内含两条可复制的 PUT 命令（main 必须走 PR、0 个审批、禁止强推与删除、管理员也受约束；Actions 只读）与后果说明；不能开（私有 + Free）→ 一行说明，strict 已在本机挡住；已保护 → 列出缺的项。
- 绝不自己调用写接口。

## 对外契约
- 环境变量 HARNESS_GH；门卡号 G-SETUP-bp。

## 如何验证
- `bash pkg/tests/test_branch_protection.sh`（152 项）。

## 遗留问题
- 真实 GitHub API 的效果需你批准门卡后在自己的仓库上验收（B1）。

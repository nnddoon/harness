# T-016 交接包：Telegram 收件箱

## 变更摘要
- `harness inbox setup`（终端输入 token，存 `~/.config/harness/telegram.json`，600；显示 10 分钟一次性配对码；把 Read deny 合并进用户级 `~/.claude/settings.json`）；`start / stop / status / run [--once]`；同一 token 只跑一个 bot（锁在 config_dir）。
- 长轮询 ≤ 20 秒；只按快照渲染门卡（审批类显示「选 A = 批准，其他 = 拒绝」、then / 解锁路径），按钮只带 `<门卡号>|<字母>`；所有批准（A）都要二次确认；只接受已配对账号，陌生人无回应；按钮回调经 record_answer 写库（via Telegram）并接续任务；API 出错不打断轮询；缺卡 3 个周期才关闭。

## 对外契约
- 配置文件字段 token, paired_user_id, chat_id, api；HARNESS_TELEGRAM_API、HARNESS_TELEGRAM_POLL。

## 如何验证
- `bash pkg/tests/test_telegram.sh`（149，假服务器）。

## 遗留问题
- 真机配对与点按需你在手机上验收（B1）。
- 一个 bot 只服务启动它的那个仓库；多仓库共用 token 需各自建 bot。

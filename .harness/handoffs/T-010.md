# T-010 交接包：答案库与门卡语义

## 变更摘要
- 答案库在仓库外：`state_dir(main)/answers/<GID>.json`（第一次答复获胜，O_EXCL）；`<GID>.meta.json` 是控制面第一次看到门卡时的快照（任务取自 GID、kind、问题、选项、解锁路径、then_*、recommended），渲染、记录、跟进、apply-gate 都只用快照；`.pr.json` / `.issue.json` 记录控制面开的 PR 与 Issue 映射；`.settling` / `.settled` 保证跟进恰好一次。
- 批准 = 字母 A；then 只允许 ready 且只在人工通道生效；卡上 `pr:`、`approve_options`、`answer:`、`status:` 都不决定结果；看板对卡与库不一致的门卡标「答案不一致」。
- 终端：`harness_lib.py show <GID>`、`answer <GID> <字母> [备注] [--yes]`（与快照不符时退出 3）、`migrate-answers`（按 v0.1 status 导入，不导入 issue 映射）。
- 修掉 v0.1 三个漏洞：旧 PR 冒充批准、伪造 Issue 标记、接续提示伪造答复。
- 启动器与 protect_paths 的 unlock 只认库里已批准、快照里的路径。

## 对外契约
- `record_answer / read_answer / record_pr / gate_state / approved_unlock_paths / show`；via ∈ {终端, 看板, GitHub, 对话, Telegram, auto, 迁移}。T-015、T-016 必须调用 record_answer，不得直接写卡。

# T-015 交接包：对话内选项卡

## 变更摘要
- `chat_answer.py`：UserPromptSubmit 中整条消息恰好是 `G-x-n: L [备注]` 时记录；PostToolUse(AskUserQuestion) 中问题以门卡号开头、问题与选项和快照逐字一致时，按所选选项的字母记录；via=对话。
- 有实际后果的门卡（then / 解锁路径 / PR / 不可逆类）选 A 不从对话记录，提示你去终端、看板或 Telegram。
- 无人值守、strict、非交互、嵌套会话时不生效；tool_input 已带 answers 时不记录。
- 每个结果都用 systemMessage 显示给你。

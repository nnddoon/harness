# T-012 交接包：审计日志与审计页

## 变更摘要
- `audit_log.py`（PreToolUse + PostToolUse，全部工具）与护栏、答复共用 `H.audit(...)`：每事件一行 JSON 写 `state_dir/audit/<日期>.jsonl`（0700/0600，O_NOFOLLOW|O_NONBLOCK，只写普通文件），单行 ≤ 4 KB，写失败不阻塞。
- 打码：GitHub / Telegram / sk- / AKIA / xox / Bearer / PEM / URL 账号密码 / token= / *PASS|SECRET|TOKEN|KEY*= 规则，在规范化副本（URL 解码、去引号与续行、\u 解码）上再匹配；heredoc 只留首行；telegram.json 与控制面 token 原文打码。
- 保留期 HARNESS_AUDIT_DAYS（默认 30）；`harness down --prune-audit`；doctor 显示审计日志大小。
- 看板 `/audit?task=&day=`：只在带令牌时可见，只读最后 2000 行。

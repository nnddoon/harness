# T-018 交接包：strict 加固

## 变更摘要
- macOS strict 启动前查钥匙串（只查存在、从不读内容）：gh:<主机>、<主机> 互联网密码、Git Credential Manager；主机来自 gh hosts 与 origin。只有退出码 44 视为不存在，其余（含超时）一律拒绝；HARNESS_ALLOW_KEYCHAIN=1 显式放行并警告；Claude Code 自身凭证只警告并建议无人值守用 CLAUDE_CODE_OAUTH_TOKEN。doctor 有「钥匙串」段。
- 验证入口文件（按 verify.sh / quick-check.sh 推出，含 cd / -C / --dir / --cwd / --prefix / -c 与一层脚本跟随；含 .npmrc、pytest 配置、conftest、同名模块等）进沙箱 denyWrite 与 control-diff；doctor 提示无法识别的运行器。
- strict 配置 disableClaudeAiConnectors: true，启动带 --strict-mcp-config 与 ENABLE_CLAUDEAI_MCP_SERVERS=false。
- 任务卡 locked_paths（含标量写法；main 上并 HEAD 卡）进 denyWrite / Edit / Write deny 与 control-diff；所有 control-diff 调用都带任务号。
- finish() 发现未跟踪 / 被忽略的入口文件时拒绝进 review（跳过 .venv、node_modules 等）。

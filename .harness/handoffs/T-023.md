# T-023 交接包：JS 测试运行器的配置文件算验证入口（0.2.2）

## 变更摘要
- verify.sh / quick-check.sh（及其调用的一层脚本）里经 npm / npx / pnpm / yarn / bun / bunx 到达的 script 被解析：运行器（jest、vitest、mocha、playwright、karma、cypress、ava、nyc、c8）→ 对应配置 glob，任一运行器出现时加 babel；`--config` 值、`node <路径>`、`./x`、`bash x` 等文件参数锁定；pre/post 钩子与嵌套 `npm run` 深度 ≤ 3。
- 只找到文件、没识别出运行器，或解析不确定（坏 JSON、script 缺失、超深、非字面 config、RecursionError）→ 保守锁全部 JS 配置。
- verify 层直接调用运行器（`jest`、`vitest run`、`node_modules/.bin/*`、`env CI=1 jest`）同样生效；workspace 选择器加 `**/` glob 与 `**/package.json`。
- control_diff 只用基准提交的 package.json 推导入口；strict denyWrite 与 doctor「## 验证入口文件」读工作区。
- VERSION 0.2.2，插件与 RELEASED.json 已重建。

## 对外契约
- `verify_entry_paths(root)` 返回值新增 JS 配置 glob；`control_diff` 签名不变。

# T-011 交接包：发布与推送移到控制面

## 变更摘要
- strict 下 Claude 与它的 hooks 不做任何 GitHub 写操作：goal / task-close 只写交接包；gate_github 的发布 hook 在 HARNESS_STRICT=1 时不动作。
- 调度器在任务进 review 后（control-diff 通过）按 SHA 推分支、开 PR（或接管控制面自己开的、base 为默认分支且同仓库的 PR），并记录合并门卡 ↔ PR；已答的合并门卡换 PR 时开新门卡 `G-Txxx-merge-<n>`。
- gate-sync 发布门卡 Issue（快照里冻结 `publisher: control`，O_EXCL 发布占位，超时先搜再重试）并推素材。
- merge-pr 只读，写入只由调度器内部调用；guard 拦截。
